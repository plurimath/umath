= Unicodemath: UnicodeMath parser for Ruby

== Purpose

Unicodemath will be a parser for
https://www.unicode.org/notes/tn28/[UnicodeMath], the linear format for
mathematics described in Unicode Technical Note 28. It is being extracted
from https://github.com/plurimath/plurimath[Plurimath] as part of
https://github.com/plurimath/plurimath/issues/530[plurimath/plurimath#530].

== Status

Work in progress, not yet released to RubyGems.

== Usage

[source,ruby]
----
require "unicodemath"

document = Unicodemath.parse("a/b")
document.expression.frac.numerator   # => Unicodemath::Model::Expression
Unicodemath.parse("1,5", decimal: ",", engine: :ruby)
----

`Unicodemath.parse` returns a `Unicodemath::Model::Document`, a typed model
declared with LutaML Model. Refused input raises `Unicodemath::ParseError`
with character and byte offsets into the input. See
link:docs/model-contract.adoc[] and link:docs/parser-contract.adoc[].
